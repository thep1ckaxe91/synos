===============================================================================
                        1. AUTHENTICATION & AUTHORIZATION
===============================================================================

Authentication Type: Bearer Token (JWT)
Header Format: Authorization: Bearer {token}

User Roles:
- Admin: Full system access
- Seller: Can create/manage artworks and auctions
- Buyer: Can purchase artworks, place bids, manage favorites

Token Management:
- Tokens are obtained through login endpoints
- Tokens should be stored securely
- Include Authorization header in all protected endpoints

7.4 PLACE BID
-------------
Endpoint: POST /buyer/auctions/{auction_id}/bids
Auth: Bearer Token (Member)
Content-Type: application/json

Request Body:
{
  "amount": 550.00
}

Requirements:
- Auction must be in "Running" status
- Bid amount must be higher than current highest bid
- Auction must not have ended
- Bidder cannot be the seller of the artwork

Success Response (200):
{
  "message": "Bid placed successfully",
  "bidAmount": 550.00,
  "currentHighestBid": 550.00
}

                          12. ERROR CODES & RESPONSES
===============================================================================

Common HTTP Status Codes:
- 200 OK: Request successful
- 201 Created: Resource created successfully
- 400 Bad Request: Invalid request data
- 401 Unauthorized: Missing or invalid authentication
- 403 Forbidden: Insufficient permissions
- 404 Not Found: Resource not found
- 500 Internal Server Error: Server error

Error Response Format:
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.4",
  "title": "Forbidden",
  "status": 403,
  "traceId": "00-c7095257478628f16dafd4b2d44b2b1c-c84aebe0b4c8e28e-00"
}

Common Error Messages:
- "Invalid token or not a seller": Wrong user role for seller endpoints
- "Artwork not found or not owned by you": Artwork ownership validation failed
- "Artwork not set for auction": Artwork sale type is not "Auction"
- "Auction start time must be in the future": Invalid auction timing
- "Failed to add artwork to favorites. Artwork may not exist or is already in favorites."
