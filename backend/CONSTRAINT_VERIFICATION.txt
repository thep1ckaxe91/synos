# ✅ CONSTRAINT VERIFICATION REPORT - Synos Database

## 🔍 Đã kiểm tra và sửa lại tất cả constraints theo database schema

### ✅ Models đã được cập nhật:

1. **Admin** ✅
   - Thêm email (unique), updated_at
   - Chuyển id từ int → long
   - Xóa username, Actions relationship

2. **Members** ✅  
   - Thêm role enum (customer, artist, admin)
   - Thêm created_at, updated_at
   - Chuyển id từ int → long
   - Unique constraint cho email

3. **Sellers** ✅
   - One-to-one relationship với Members
   - Thêm website field, xóa location
   - Foreign key: sellers.id → members.id

4. **Artworks** ✅
   - Thêm is_for enum (AUCTION, FIXED)
   - Thêm fixed_price, status enum
   - Đổi dimensions, chuyển price → fixed_price
   - seller_id NOT NULL

5. **Auctions** ✅ (Bảng mới)
   - Tạo model mới cho đấu giá
   - Foreign keys: artwork_id, winner_bid_id
   - Status enum: scheduled, running, ended

6. **ExhibitionArtwork** ✅
   - Composite primary key (exhibition_id, artwork_id)
   - Thêm display_from, display_to
   - Xóa display_order, start_date

7. **Orders** ✅
   - Thêm payment_time, status enum
   - Chuyển payment_date → payment_time
   - user_id NOT NULL

8. **OrderItems** ✅
   - Xóa size, receive_at
   - Thêm total field (decimal)
   - Cả order_id và artwork_id NOT NULL

9. **Favorite** ✅
   - Composite primary key (artworks_id, user_id)
   - Xóa auto-increment id

10. **Commission** ✅
    - Commission_type enum (percentage, fixed)
    - value field NOT NULL
    - Decimal precision 18,4

✅ **members.id** ← sellers.id (One-to-One)
✅ **members.id** ← orders.user_id  
✅ **members.id** ← auctions.winner_bid_id
✅ **members.id** ← favorite.user_id
✅ **artworks.id** ← artwork_images.artwork_id
✅ **artworks.id** ← auctions.artwork_id
✅ **artworks.id** ← order_items.artwork_id
✅ **artworks.id** ← exhibition_artworks.artwork_id
✅ **artworks.id** ← commissions.artwork_id
✅ **artworks.id** ← favorite.artworks_id
✅ **categories.id** ← artworks.category_id
✅ **orders.id** ← order_items.order_id
✅ **exhibitions.id** ← exhibition_artworks.exhibition_id

### 📊 Unique Constraints:
✅ admin.email
✅ members.email  
✅ categories.name
✅ categories.slug
✅ orders.order_number

### 🗂️ Composite Keys:
✅ exhibition_artworks (exhibition_id, artwork_id)
✅ favorite (artworks_id, user_id)

### 🔢 Data Types đã sửa:
✅ ID fields: int → long (BIGINT)
✅ Decimal precision: 18,4 cho auctions, commissions
✅ Decimal precision: 12,2 cho orders, artworks
✅ Varchar lengths khớp với schema
✅ Enum conversions to string
